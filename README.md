# TechZiouz React Responsive Website

This is the React/Vite version of the TechZiouz multi-page website.

## Requirements
- Node.js 18+ recommended
- VS Code recommended

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Structure

- React + Vite
- React Router
- Responsive CSS
- Local TechZiouz logo and hero video in `public/assets`
- Multiple routes/pages
- Detailed service pages
- Practical Computer Labs: Plus One, Plus Two, Degree
- WhatsApp / email / LinkedIn / WhatsApp Community footer links

Instagram was not added as a live link because an Instagram URL was not provided.
